# 6. **ユースケース（何に使う？）**：共有（Share）

あなたの既存画面・業務フローから、**共有**は下記が実務で刺さります（ページ名は実装済ファイルに合わせて記載）。

1. **顧客・店舗の共有リンクを送る**（例：`HomePage.tsx`／`StoresPage.tsx`）

   * 営業・サポートが店舗詳細や請求設定ページの URL を**LINE・メール**で即共有。
   * 例：`HomePage.tsx` は Stripe 顧客データを取得しているので（`/api/stripe/customer`）共有対象のページ URL を合成しやすい。&#x20;

2. **サブスク請求・決済ページの共有**（`StoreServicesPage.tsx`, `SubscriptionDetailPage.tsx`）

   * お客様に**支払い方法更新／数量変更申請ページ**を共有。Stripe連携画面と相性よし。 &#x20;

3. **端末（デバイス）操作手順の共有**（`StoreDevicesPage.tsx`）

   * 端末引き渡し・回収時に、スタッフ間で**端末手順ページ**（社内Wiki）や**該当デバイス URL**を共有。&#x20;

# 7. **ユースケース（何に使う？）**：QR 読み取り

1. **端末シリアルの現場登録**（`StoreDevicesPage.tsx`）

   * 端末本体の QR（シリアル番号）を**その場で読み取り**→ `/devices/:serial` に遷移して登録/更新。&#x20;

2. **店舗受付でのチェックイン**（`HomePage.tsx`）

   * 店舗に貼った QR（`/store/:id`）をスキャン→**対象店舗画面**へ直接遷移して作業。&#x20;

3. **Stripe 顧客 QR**

   * Stripe 顧客 ID を埋めた QR をスキャン→**請求履歴**や**決済設定**にダイレクト遷移（`/payment-history/:customerId` 等）。ルーティングは既に存在。&#x20;

# 8. 共有/QR を React から呼ぶアダプタを追加（**新規ファイル・全文**）

## 追加：`client/src/native.ts`

```ts
export function isNative(): boolean {
  return Boolean((window as any)?.Capacitor?.isNativePlatform);
}

// 共有シートを開く（アプリ）/ クリップボードにコピーして案内（Web）
export async function share(opts: { title?: string; text?: string; url?: string; dialogTitle?: string }) {
  if (isNative()) {
    const { Share } = await import('@capacitor/share');
    return Share.share(opts);
  } else {
    const clip = [opts.text, opts.url].filter(Boolean).join('\n');
    if (clip) {
      await navigator.clipboard.writeText(clip);
      alert('共有はアプリ版で動作します。内容をクリップボードにコピーしました。');
    } else {
      alert('共有はアプリ版でご利用ください。');
    }
  }
}

// QR コード/バーコードを読み取る（アプリ）/ 案内（Web）
export async function scanQr(onResult: (content: string) => void) {
  if (!isNative()) {
    alert('QR読み取りはアプリ版でご利用ください');
    return;
  }
  const { BarcodeScanner } = await import('@capacitor-community/barcode-scanner');

  // カメラ権限の確認と要求
  const perm = await BarcodeScanner.checkPermission({ force: true });
  if (!perm.granted) {
    alert('カメラ権限が必要です');
    return;
  }

  await BarcodeScanner.hideBackground();
  try {
    const result = await BarcodeScanner.startScan();
    if (result?.hasContent) onResult(result.content);
  } finally {
    await BarcodeScanner.showBackground();
  }
}
```

### これは何か / 何をするか

* `isNative()` で **Capacitor 殻内かどうか判定**。
* `share()` は **共有シート**（アプリ）／**コピー**（Web）。
* `scanQr()` は **スキャン→コールバック**（アプリ）／**案内**（Web）。

### 反映

* Replit のエディタで保存。

# 9. **UI コンポーネント**として 2 ボタンを提供（**新規ファイル・全文**）

> 既存ページ（`HomePage.tsx`、`StoreDevicesPage.tsx` など）に**貼るだけ**で使える最小 UI を用意します。

## 追加：`client/src/components/native/ActionBar.tsx`

```tsx
import React from 'react';
import { share, scanQr } from '../../native';

type Props = {
  shareText?: string;
  shareUrl?: string;
  onScanned?: (content: string) => void;
};

export default function ActionBar({ shareText, shareUrl, onScanned }: Props) {
  return (
    <div style={{ position: 'fixed', right: 16, bottom: 16, display: 'flex', gap: 12, zIndex: 9999 }}>
      <button
        onClick={() => share({ text: shareText, url: shareUrl, title: '共有', dialogTitle: '共有' })}
        style={{ padding: '10px 14px', borderRadius: 12 }}
      >
        共有
      </button>
      <button
        onClick={() => scanQr((c) => onScanned ? onScanned(c) : (location.href = `/devices/${encodeURIComponent(c)}`))}
        style={{ padding: '10px 14px', borderRadius: 12 }}
      >
        QR読み取り
      </button>
    </div>
  );
}
```

### これは何か / 何をするか

* **固定配置の 2 ボタン**（共有／QR）を、どの画面にも簡単に貼れるようにしたコンポーネントです。
* `shareText`/`shareUrl` を渡せば共有に利用、`onScanned` を渡せばスキャン後の処理を上書き可能。

### 反映

* Replit のエディタで保存。

# 10. 既存ページへの組み込み例（**差し込みポイントの明示**）

> 既存の画面コード全文は大きいので、**追記行**を明示します。
> ファイル構造・ルーティングは把握済（`App.tsx` 参照：`/payment-history/:customerId` や `/store/:id/devices` 等） 。

### 例 A：`HomePage.tsx` に「共有＋QR」

（Stripe 顧客データを取得しているため、**請求履歴ページ**などの共有に最適）&#x20;

**追記するコード（ファイル末尾の `return` のすぐ内側、`<AppLayout>` の子要素として）**：

```tsx
// 先頭に追加
import ActionBar from "@/components/native/ActionBar";

// ... HomePage の return JSX の末尾付近に追加
<ActionBar
  shareText="お客様のポータルはこちらです"
  shareUrl="https://YOUR-PROD-DOMAIN.example.com/payment-history/＜顧客ID＞"
  onScanned={(content) => {
    // 例：スキャンした ID を顧客IDとして扱い、請求履歴に遷移
    location.href = `/payment-history/${encodeURIComponent(content)}`;
  }}
/>
```

### 例 B：`StoreDevicesPage.tsx` に「共有＋QR」

（**端末シリアル**を QR で読み取り → `/devices/:serial` へ。画面と強い親和性）&#x20;

**追記するコード（同様に末尾へ）**：

```tsx
import ActionBar from "@/components/native/ActionBar";

<ActionBar
  shareText="この店舗の端末ページです"
  shareUrl={location.href}
  onScanned={(serial) => {
    // 読み取ったシリアルで端末詳細/登録画面へ
    location.href = `/devices/${encodeURIComponent(serial)}`;
  }}
/>
```

> **ポイント**：ActionBar を使えば、**どのページにも一切のレイアウト崩れなく 2 ボタンを常設**できます。
> 必要に応じて、`shareUrl` は該当ページの URL（`location.href`）や、特定の操作ページに差し替えてください。
